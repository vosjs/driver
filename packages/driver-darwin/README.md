# @vosjs/driver-darwin

The macOS helper for [`@vosjs/driver`](https://www.npmjs.com/package/@vosjs/driver): one universal binary (Apple silicon and Intel), macOS 14 or later.

Install `@vosjs/driver`. It brings this package where it runs and finds the helper in it.

Source and documentation: [github.com/vosjs/driver](https://github.com/vosjs/driver).
